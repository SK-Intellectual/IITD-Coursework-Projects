# IIT Delhi Coursework Projects

A collection of academic, computational, and engineering projects completed as part of my coursework at **IIT Delhi**.

This repository brings together selected projects, assignments, computational studies, and technical work undertaken during my academic coursework. The projects span different areas of engineering, mathematical modeling, computation, data analysis, and scientific programming.

## About

These projects represent coursework-based work completed during my time at IIT Delhi. They include both individual and course-related projects, with an emphasis on applying theoretical concepts to practical and computational problems.

The repository is intended to serve as a record of my academic work and to provide an overview of the technical skills and problem-solving approaches developed through my coursework.

## Projects

The repository includes projects covering areas such as:

* Mathematical and computational modeling
* Engineering analysis and simulation
* Numerical methods
* Scientific programming
* Data analysis and visualization
* Computational problem solving
* Machine learning and data-driven methods
* Other course-specific technical projects

Each project is maintained in its respective directory with relevant documentation and supporting material where available.
