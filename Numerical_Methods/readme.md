# Numerical Methods for Chemical Engineering

Numerical methods play a crucial role in solving complex problems encountered in chemical engineering, where analytical solutions are often difficult or impossible to obtain.

This repository is a collection of **numerical methods, algorithms, and computational implementations** for common mathematical problems encountered in chemical engineering.

## Topics Covered

### Root Finding

Methods for solving nonlinear algebraic equations, including:

* Bisection Method
* Newton-Raphson Method
* Other iterative root-finding techniques

### Numerical Integration

Methods for approximating definite integrals, including:

* Trapezoidal Rule
* Simpson's Rule
* Numerical integration of engineering functions

### Ordinary Differential Equations (ODEs)

Numerical approaches for solving first- and higher-order ordinary differential equations, including:

* Euler's Method
* Runge-Kutta Methods
* Initial-value problems
* Engineering system simulations

### Partial Differential Equations (PDEs)

Numerical techniques for solving common PDEs encountered in transport phenomena and chemical engineering, including:

* Heat Equation
* Diffusion Equation
* Finite-difference approaches
* Boundary- and initial-value problems

### Linear Algebra

Computational techniques for solving systems of linear equations and related problems, including:

* Gaussian Elimination
* LU Decomposition
* Matrix-based solution methods
